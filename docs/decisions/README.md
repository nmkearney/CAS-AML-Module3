# Design decisions

One short file per decision, numbered in order: `0001-short-title.md`.

```markdown
# 0001: Title

- Status: accepted | superseded by 0007
- Date: YYYY-MM-DD

## Context
What needed deciding, and the facts or constraints behind it.

## Decision
What was chosen.

## Consequences
What this makes easier or harder, and what to revisit if the prototype continues.
```
